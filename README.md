# 🌸 Anime Notes

A cute, Japanese anime girl-inspired notes app with a **white & pink** theme. Organize your notes into categories/folders, pin important notes, and enjoy a kawaii UI with sparkles, stars, and an anime mascot — all programmatic, no image assets needed.

> **Note:** This theme is deliberately **NOT** sakura / cherry-blossom themed. The aesthetic uses shoujo manga motifs: sparkles, stars, hearts, and ribbons.

## ✨ Features

- **Notes** — Create, edit, delete, and pin notes
- **Categories / Folders** — Organize notes into custom folders with emoji
- **Search** — Search notes by title and content
- **Filter** — Filter by category or pinned notes
- **Color Coding** — 8 pastel colors to tag your notes
- **Anime Mascot** — A kawaii anime girl mascot drawn programmatically
- **Decorative Elements** — Sparkles, stars, hearts scattered across screens
- **Persistent Storage** — All notes saved locally via AsyncStorage
- **Offline First** — No internet connection required

## 🎨 Theme

- **Colors:** White backgrounds with pink accents (#FF69B4 primary)
- **Aesthetic:** Shoujo manga / anime girl style
- **Decorations:** Sparkles (✨), stars (⭐), hearts (💤) — no sakura petals
- **Mascot:** Programmatic anime girl with pink hair, big eyes, and blush

## 📦 Setup & Run

### Prerequisites

- **Node.js** 18+ (recommended: 20+)
- **Expo CLI** (comes with Expo SDK 57)
- **Expo Go** app on your phone (iOS / Android) OR an emulator

### Install & Run

```
# 1. Navigate to project folder
cd anime-notes-app
# 2. Install dependencies
nmp install
# or: npx expo install
# 3. Start the dev server
npx expo start
# or: npm start
# 4. Open the app:
#    - Press 'i' for iOS simulator
#    - Press 'a' for Android emulator
#    - Scan QR code with Expo Go app on your phone
```
